# Security

Report security issues through [private vulnerability reporting](https://github.com/Ryanhu2001/Transpose/security/advisories/new). Include the affected version or commit and a minimal reproduction using public sample text. Do not post keys, authentication files or private screenshots in public issues.

API keys use macOS Keychain; OCR is local. API and CLI requests send text and applicable preferences to the configured service. See [Privacy](docs/privacy.md).

Expose native capabilities through explicit desktop commands. Keep keys out of browser storage, logs and preview fixtures. Review permission, process-execution and credential changes across both Rust and Swift.
